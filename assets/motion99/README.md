# MOTION 99 — мастер-класс и курс моушн-дизайна

Интерактивный курс по game feel / juice / Transform UI / award-winning переходам 2026.
Всё на чистом HTML/CSS/JS, без зависимостей. Каждый приём — живое демо с управляемыми
параметрами и копируемым кодом.

## Запуск
```bash
python3 -m http.server 8080 --bind 0.0.0.0 --directory .
# открыть http://localhost:8080
```

## Файлы
- `index.html` — разметка всех модулей и сниппеты кода (`<script type="text/template">`)
- `css/styles.css` — дизайн-система Glass/Aurora + стили всех демо
- `js/app.js` — роутер, жизненный цикл демо (пауза вне экрана), тикер, Spring, bez-solver, шум
- `js/demos-a.js` — движки модулей 1–2
- `js/demos-b.js` — движки модулей 3–4
- `js/demos-c.js` — движки модуля 5 и хранилища

## Инженерные правила, зашитые в сайт
1. Анимируем только `transform / opacity / filter` (композитор).
2. Пружины интегрируются полу-неявным Эйлером с подшагом ≤ 1/240с — параметры не «плывут» на 120 Гц.
3. Все фоновые симуляции останавливаются, когда модуль не на экране (экономия батареи).
4. `prefers-reduced-motion` и тумблер Reduce Motion: движение не удаляется, а заменяется кросс-фейдом.
5. Velocity handoff: скорость жеста передаётся пружине при отпускании.
